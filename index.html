Select
Click an object to select it, drag it to move it.
Draw
Click and drag to freehand a track, slide or wall.
Ball
Click the canvas to place a ball.
Box
Click the canvas to place a box.
Play / Stop
Play starts gravity and physics. Stop puts everything back where you left it.
Clear
Remove everything from the canvas.
Export
Save the current scene to a file.
Import
Load a saved scene file, replacing the canvas.
Right-click
Lock or unlock an object. Locked objects (padlock) stay fixed during Play.
Blue handle
On a selected ball, drag it around the ball to set its initial spin.
Right-click an object to lock/unlock it · select a ball and drag its blue handle to set spin
